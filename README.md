## What this is

The public side of Psanctuary's reading room. Drafts are read first by Psanctuary's people in a private room; a page
arrives here only when an officer lists it in that room's allowlist, and a workflow copies it after a check that stops
anything private or secret-shaped. The front page (`index.html`) is plain HTML with no build step, so GitHub Pages serves
it as it is.

## Please do not edit this repository by hand

Everything here is copied in by a workflow, and the next copy replaces hand edits. To change a page, change it in the
private room (or ask someone who can). The branch keeps a deletion-only rule so the copy can always arrive.

## Ask for access to the members' room

Write to [info@psanctuary.org](mailto:info@psanctuary.org) or use [the contact form](https://www.psanctuary.org/contact)
and say you would like to read the drafts; include your GitHub username. More:
[how Psanctuary welcomes members and their helpers](https://github.com/psanctuary/.github/blob/main/ONBOARDING.md).
